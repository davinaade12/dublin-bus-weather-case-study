Weather and Bus Reliability in Dublin: A 2025–2026 Case Study
For this project, I will create a web-based analytics system that investigates whether rainfall affects Dublin Bus punctuality at a small number of selected bus stops.

The system will collect real-time bus and weather data, store it in a database, and analyse how bus arrival times change during different weather conditions. The dashboard will display the results using charts and visualisations, including a heatmap and a 30-day trend view. Users will also be able to export the data as a CSV file.

The project will apply concepts covered in class, including database design, data analytics, data visualisation, web development, testing, security, and accessibility. The final report will discuss the methods used, the results obtained, the limitations of the study, and recommendations for future improvements.
